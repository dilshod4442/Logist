# LogiLearn

LogiLearn — локальный образовательный портал по логистике на Django. В нём есть каталог тем, лекции, практические задания, учебные файлы и видео, тестирование с серверной проверкой, глоссарий, прогресс пользователя, Django Admin и компактная пользовательская панель управления.

## Запуск в Windows

В PowerShell из папки проекта выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed_logilearn
python manage.py createsuperuser
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`. Команда `seed_logilearn` необязательна: она добавляет стартовые дополнительные материалы, не выдавая их за цитаты из исходных документов. Суперпользователь создаётся только интерактивной командой `createsuperuser`; пароль не хранится в проекте.

## Управление содержанием

После входа под сотрудником перейдите в `/dashboard/` для создания тем и загрузки файлов. Полная работа с разделами, лекциями, практикой, видео, тестами, вопросами, вариантами ответов, глоссарием и настройками сайта доступна в `/admin/`.

Для публикации установите статус **«Опубликовано»**. Черновики и скрытые объекты не отображаются посетителям. Чтобы добавить тест, создайте тест, затем вопросы и варианты ответов; правильные варианты задаются только в административной панели и не отправляются на страницу теста заранее.

## Файлы и большие загрузки

Допустимые расширения: PDF, DOC/DOCX, PPT/PPTX, XLS/XLSX, CSV, JPG/JPEG/PNG/WEBP, ZIP, MP4 и WEBM. Имена файлов заменяются случайными безопасными идентификаторами, опасные расширения отклоняются, а лимит задаётся `MAX_UPLOAD_SIZE` (по умолчанию 200 МБ). Django направляет файлы больше 2 МБ во временное файловое хранилище, поэтому они не загружаются целиком в память.

Для рабочего сервера задайте такие же лимиты в Nginx (`client_max_body_size`), Apache или в настройках облачного хранилища. Предельный размер также зависит от свободного места, прокси и внешнего хранилища. Для больших роликов используйте внешнее совместимое хранилище и поле внешней видеоссылки.

## Подготовка к серверу

1. Скопируйте `.env.example` в безопасное хранилище переменных окружения и задайте новый `DJANGO_SECRET_KEY`.
2. Укажите `DJANGO_DEBUG=False` и реальные `DJANGO_ALLOWED_HOSTS`.
3. Выполните `python manage.py check --deploy`, `python manage.py migrate` и `python manage.py collectstatic`.
4. Раздавайте `staticfiles/` и `media/` через веб-сервер или объектное хранилище. Не используйте `runserver` в production.

## Проверки

```powershell
python manage.py check
python manage.py test
```

Тесты покрывают публичность тем, серверное сохранение прогресса, подсчёт теста, лимит попыток и блокировку опасного расширения. Для локальной разработки используется SQLite; для PostgreSQL замените раздел `DATABASES` в `config/settings.py` через переменные окружения или отдельный production settings-модуль.
